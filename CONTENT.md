# CONTENT.md

Everything you write goes here. **Leave anything blank and the site skips it** —
the page still looks finished, so fill this in in any order and stop whenever.

**Three rules:** don’t change the `## PAGE:` lines · fields start with `@` ·
list items start with `- `. That’s it.

Titles, subtitles and the award citations are already written and live in the code —
they are not your job. This file is only the parts that have to come from you.

## If you only have an hour, write these nine

They carry most of the emotional weight. Everything else is a bonus.

1. **`/letter`** — the final letter. Do this one first and give it the most time.
2. `/guiding-star/things-you-taught-me` — three lessons
3. `/guiding-star/things-i-never-say-enough` — four thank-yous
4. `/heart/the-kindness-you-carry`
5. `/magic/the-mum-isms` — her catchphrases. Fastest page here, and she will love it.
6. `/magic/your-superpowers` — four, funny
7. `/professor/beyond-the-blackboard`
8. `/wishes/a-thousand-little-wishes` — eight one-line wishes
9. The seven `@personal` lines in the Hall of Fame — one sentence each

Marked ★ below. Short is fine everywhere — two honest sentences beat a paragraph.

## Extra fields, if you find more time later

Any page above also accepts these. Add the `@field` line and write underneath.

| Field | Appears as |
| --- | --- |
| `@intro` | a short opening line above the body, in larger type |
| `@quote` | a highlighted pull-quote in an ornamental frame |
| `@anecdote` | a story in a softly tinted panel |
| `@photoCaption` | a handwritten caption under that page’s photograph |
| `@closing` | a final centred line in delicate italics |
| `@title` / `@subtitle` | overrides the written-in defaults |

Chapter landing pages (`/guiding-star`, `/heart`, `/professor`, `/memories`, `/magic`,
`/hall-of-fame`, `/wishes`) take `@intro` and `@photoCaption` too — add a
`## PAGE: /heart` block if you want them.
